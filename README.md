# Wardrobe Archive · 취향의 옷장

남성복 40종·여성복 28종, 총 68종의 의상 아카이브입니다. 모든 코디 68종에 이미지와 의상 프롬프트를 제공합니다.

## 기능
- 계절 및 스타일 필터, 한글·영문 검색
- 이미지 확대 및 이미지 다운로드 (PNG·JPG)
- 의상 태그 복사
- 브라우저에 저장되는 즐겨찾기
- 모바일 2열 레이아웃

## GitHub Pages 설정
저장소 Settings → Pages → Build and deployment에서 Deploy from a branch를 선택하고, main 브랜치의 /(root)를 저장합니다.

## 코디 추가
1. images/에 이미지 파일을 추가합니다.
2. data.js의 OUTFITS 배열에 고유 id, wardrobe(men 또는 women), name, season, category, style, prompt, desc, image, keywords를 추가합니다.
3. 커밋하면 Pages가 새 파일을 배포합니다.

## 이미지 사용
상세 화면의 다운로드 버튼으로 이미지를 저장한 뒤 이미지 생성 도구의 의상 레퍼런스로 선택합니다. 이미지와 태그가 생성 결과를 보장하지는 않습니다.

계정·서버·API 키 없이 동작합니다. 즐겨찾기는 현재 브라우저에만 저장됩니다.

## 스타일 확장
긱시크 프레피, Y2K 스트리트웨어, 맥블링 Y2K, 인디 슬리즈, 펑크 프레피, 아쿠비 Y2K를 각 3종씩 추가했습니다. 전체 신규 코디 구성은 [STYLE-CATALOG.md](STYLE-CATALOG.md)를 참고하세요.

올드머니 4종: 네이비 클럽, 캐시미어 위켄드, 리비에라 리넨, 컨트리 에스테이트.

이 분류는 사이트 탐색을 위한 묶음입니다.

## 남성복 / 여성복 탭
탭 선택에 따라 목록과 포인트 색상이 변경됩니다. 남성복은 딥그린, 여성복은 더스티 모브입니다. 계절 개수와 즐겨찾기 개수는 현재 옷장 기준입니다. 전환 시 검색과 필터를 초기화하며 즐겨찾기 저장 내용은 유지합니다. 기존 mw-favorites 저장 키를 유지하여 남성복 즐겨찾기를 보존합니다. 마지막 선택한 옷장은 wa-wardrobe에 저장합니다. 탭은 방향키·Home·End로도 전환할 수 있습니다.

## 파츠별 색상 편집

상세 화면에서 각 코디의 재킷, 상의, 하의, 신발, 가방 등에 추천색을 따로 적용할 수 있습니다. 선택한 파츠의 주 색상만 프롬프트에서 바꾸며 안감·단추·버클 등 뒤에 붙은 장식 설명은 보존합니다.

1. 파츠별 색상 칩을 한 번 탭하면 사진의 해당 옷에 바로 색이 입혀집니다. 색상 칩은 가로로 넘겨 볼 수 있습니다.
2. 원본 비교로 원래 사진과 비교합니다.
3. 색상 변경 이미지 다운로드로 원본 해상도의 PNG를 저장합니다. 원본 이미지 다운로드는 별도로 유지됩니다.

파츠별 영역은 images/masks/코디ID.png에 미리 지정해 두었습니다. 픽셀 값이 (파츠 순서 + 1) × 16인 라벨 이미지이며, 파츠 순서는 프롬프트에서 옷이 나오는 순서와 같습니다. 사진에 보이지 않는 파츠는 태그만 바뀝니다. 코디를 추가하거나 프롬프트의 옷 순서를 바꾸면 마스크도 다시 만들어야 합니다.

색상 보정은 옷의 주 색상만 바꾸고 배색·스트라이프·장식처럼 다른 색은 유지하며, 명암과 질감을 살립니다. 조합 저장은 현재 브라우저의 localStorage에 색상 선택을 저장합니다. 다른 기기와 동기화되지 않습니다. 서버나 유료 API 없이 브라우저 Canvas로 처리합니다.

파츠별 추천색은 parts.js의 CONCEPT_PALETTES(세부 스타일별 대표색)와 SEASON_ACCENTS(계절 포인트색)로 구성합니다. 대표색 5개는 앞에 고정하고 나머지는 코디·파츠마다 순서를 바꿔 보여 줍니다. 데님은 워시 색, 신발·벨트·가방은 컨셉에 맞는 기본색, 양말·타이츠는 기본 레그웨어 색을 먼저 보여 줍니다.

검증: `node tests/parts.test.cjs`

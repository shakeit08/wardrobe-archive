# Wardrobe Archive · 남자의 옷장

인물 없는 남자 코디 이미지 40종과 의상 태그를 모아 둔 정적 웹사이트입니다.

## 기능
- 계절 및 스타일 필터, 한글·영문 검색
- 이미지 확대 및 이미지 다운로드 (PNG·JPG)
- 의상 태그 복사
- 브라우저에 저장되는 즐겨찾기
- 모바일 2열 레이아웃

## GitHub Pages 설정
저장소 Settings → Pages → Build and deployment에서 Deploy from a branch를 선택하고, main 브랜치의 /(root)를 저장합니다.

## 코디 추가
1. images/에 이미지 파일을 추가합니다.
2. data.js의 OUTFITS 배열에 고유 id, name, season, category, style, prompt, desc, image, keywords를 추가합니다.
3. 커밋하면 Pages가 새 파일을 배포합니다.

## 이미지 사용
상세 화면의 다운로드 버튼으로 이미지를 저장한 뒤 이미지 생성 도구의 의상 레퍼런스로 선택합니다. 이미지와 태그가 생성 결과를 보장하지는 않습니다.

계정·서버·API 키 없이 동작합니다. 즐겨찾기는 현재 브라우저에만 저장됩니다.

## 스타일 확장
긱시크 프레피, Y2K 스트리트웨어, 맥블링 Y2K, 인디 슬리즈, 펑크 프레피, 아쿠비 Y2K를 각 3종씩 추가했습니다. 전체 신규 코디 구성은 [STYLE-CATALOG.md](STYLE-CATALOG.md)를 참고하세요.

올드머니 4종: 네이비 클럽, 캐시미어 위켄드, 리비에라 리넨, 컨트리 에스테이트.

## 스타일 분류
상단 필터는 4개 대주제로 표시하며 카드와 상세 화면에는 기존 세부 스타일을 유지합니다. category에는 대주제, style에는 세부 스타일을 입력합니다. 두 항목 모두 검색할 수 있습니다.

| 대주제 | 포함 스타일 |
|---|---|
| 캐주얼·미니멀 | 캐주얼, 미니멀 |
| 클래식·올드머니 | 클래식, 포멀, 올드머니 |
| 프레피 | 프레피, 긱시크 프레피, 펑크 프레피 |
| 스트리트·Y2K | 스트리트, Y2K 스트리트웨어, 맥블링 Y2K, 아쿠비 Y2K, 인디 슬리즈 |

이 분류는 사이트 탐색을 위한 묶음입니다.

테디 스노우 1종 추가: 스트리트·Y2K 대주제에 소프트 Y2K 겨울 코디를 배치했습니다.

브라운 인터루드와 네이비 몽마르트르 2종 추가. 영문 태그는 가중치 없이 제공합니다.

클래식 캐주얼 3종 추가: 바시티 위켄드, 해링턴 산책, 데님 스탠더드.
